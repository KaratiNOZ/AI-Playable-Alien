# Alien Playable — играть за Чужого, лицехвата и андроидов в Alien: Isolation

**Бета.** Мод сделан под **Steam-версию** игры (AI.exe от 17.02.2015). На другой сборке (GOG, Epic, другое обновление)
установщик и инжектор предупредят (окно сразу на русском и английском), что часть функций или весь мод может не работать,
и всё равно поставят и запустят его; в меню мода тоже будет эта строка.
Windows 10/11 (на 7 должно работать, но не проверялось); ничего доустанавливать не нужно — всё собрано в самих файлах мода.

**Быстрый старт:** распакуй архив куда угодно (не в Program Files) → закрой игру → `AlienModSetup.exe` → «Установить» →
запусти игру → ярлык «AlienMod» на рабочем столе (или `AlienInjectorUI.exe`) → в игре **Delete** — меню (клавишу можно сменить; **Insert** открывает меню всегда).
Нашёл баг — пришли `AlienModUI.log` (лежит рядом с модом) и что делал.

# AlienMod — отдельная сборка (exe + dll)

`AlienInjectorUI.exe` + `AlienModUI.dll` — мод «играть за Чужого» с меню ImGui, без DevTools.
Одно окно «Alien Playable», слева страницы: «Главное», «Камера», «Движение», «Чужой», «Атака и ИИ», «Лицехваты», «Вентиляция», «Спавн», «Мультиплеер», «Экран», «Клавиши», «Мод», «Фоторежим», «Уровни», «Лог» — у каждой настройки своё место, листать не надо. Оформление — меню друга (booster_ui) в цветах терминала Seegson, шрифты — из самой игры.
(Старые `AlienInjector.exe` / `AlienMod.dll` — первая сборка, больше не нужны.)

1. `AlienModSetup.exe` — один раз (и после обновления мода), игра закрыта. Сам находит Alien: Isolation (Steam, GOG,
   Epic, типовые папки), не нашёл — «Обзор…» открывает обычный выбор папки Проводника. «Установить» кладёт в игру
   деревья поведения Чужого и лицехватов с ветками мода (оригинал — рядом, `.bak`), «Удалить из игры» возвращает
   оригинал. Галочка — ярлык «AlienMod» на рабочем столе, «Запустить игру» — через Steam или `AI.exe`.
2. Запусти игру — внедрять можно когда угодно: в главном меню или прямо на уровне (мод сам найдёт в памяти уже
   созданные деревья Чужого и лицехватов, это пара секунд).
3. `runUI.bat` (или `AlienInjectorUI.exe`) — дождётся AI.exe и фокуса окна игры, внедрит `AlienModUI.dll`, покажет лог (`AlienModUI.log`).
4. **Delete** (или своя клавиша из «Клавиш») или **Insert** — меню. Первые 30 с в правом нижнем углу висит подпись «AlienMod» — значит, меню живо.

## Управление

Раскладка как в обычном экшене: всё под левой рукой вокруг WASD, атака мышью, редкие вещи на F-клавишах.

F12 и Print Screen до игры доходят всегда, так что скриншоты Steam работают и за Чужого, и в фоторежиме.
После Alt+Tab мод не реагирует на клавиши и мышь, пока окно игры снова не станет активным.

Все буквы и F-клавиши из таблиц — **по умолчанию**. Их можно поменять в меню, в разделе «Клавиши»: нажимаешь на клавишу
действия, потом новую, а занятая клавиша меняется местами с другим действием. Постоянные клавиши не меняются:
WASD, Ctrl/Shift/Пробел, мышь, Esc, Delete/Insert и клавиши фоторежима.

При первом запуске сверху экрана идёт **обучение** по шагам. Пропустить его или пройти заново можно в меню, в разделе «Экран».
Пока Чужой охотится, внизу показано **имя цели** и расстояние до неё.

**Главное (работает всегда):**

| Клавиша | Что делает |
|---|---|
| **B** | играть за Чужого / вернуться к Аманде |
| **WASD** | идти: без модификаторов — шаг, **Ctrl** — тихо, **Shift** — быстро, **Пробел** — бег |
| мышь | крутить камеру |
| **колесо** | камера ближе/дальше (из головы — вперёд/назад) |
| **Shift / Ctrl + колесо** | камера выше/ниже / левее/правее |
| **средняя кнопка** | сбросить камеру |
| **ЛКМ / ПКМ** | атака / сменить цель |
| **E** | вентиляция: спрятаться / вылезти здесь / отменить (по ситуации) |
| **Q** | вылезти из вентиляции рядом с Амандой |
| **V** | вид: из-за спины / из головы |
| **X** | застрял: встать позади Аманды (в вентиляции — вылезти у неё) |
| **Z** (держать) | LOOK: Чужой встаёт и смотрит головой и корпусом туда, куда смотрит камера (как осмотр ИИ; «как раньше» — в меню) |
| **G** | голос Чужого (Shift — случайный по обстановке: обычно звуки поиска, «заметил» — только когда цель — человек рядом) |
| **H** | играть за лицехвата (ещё раз — за следующего; B — назад к Аманде) |
| **Esc** | пауза игры: пока меню паузы открыто, мышь и клавиши у игры, а Чужой или лицехват остаётся твоим; игра пошла — управление снова у тебя |
| **F2 / F3** | спрятать/показать подсказки на экране / карту вентиляции |
| **F9** | фоторежим |
| **Delete / Insert** | меню (Delete меняется в «Клавишах») |

E, Q, V, Z, G (и R, F, C ниже) работают только когда играешь за Чужого. В этот момент ввод до Аманды не доходит,
поэтому с её клавишами (E — использовать и т. п.) ничего не путается.

**Дополнительно** (работает всегда; «Простое управление» только прячет эти клавиши из подсказок на экране):

| Клавиша | Что делает |
|---|---|
| R | стрейф вкл/выкл (в вентиляции сам на паузе) |
| F | Аманда следует за Чужим вкл/выкл (по умолчанию выключено) |
| C | режим пути: заходить в горизонтальные шахты |
| F1 | список персонажей (стрелки, Enter — Чужой к нему, Backspace — притащить) |
| F4 | ИИ по кругу: ручное → охотится не на Аманду → полный |
| F5 | аварийный сброс |
| F7 / Shift+F7 / Ctrl+F7 | спавн: найти и листать / назад / искать заново |
| F8 / Shift+F8 | заспавнить / тот же ещё раз |

Когда камера у Аманды, стрелки ведут Чужого, не забирая камеру.

**Камера.** Настраивается прямо в игре колесом мыши, а в меню (раздел «Камера») есть ползунки (расстояние, высота, плечо, сдвиг
камеры из головы) и готовые варианты: «Обычная», «Ближе», «Дальше», «Сверху», «Другое плечо». Настройка запоминается сама
(`AlienModUI.ini`, раздел `[camera]`) и сохраняется после перезапуска. В узких шахтах мод, как и раньше, сам ставит ближнюю камеру, а на выходе возвращает твою.

**Вид из головы** — два варианта (страница «Камера»): «Свободная» — камера у головы Чужого, но крутится мышью, как за
спиной, и Чужой идёт туда, куда смотришь; «Прибита к кости» — как в игре, кадр поворачивается вместе с головой.
**Развороты на месте** (страница «Движение», отдельно из головы и за спиной): стоит, а камера смотрит в сторону —
Чужой доворачивается анимацией разворота на месте (IDLE_TURN 90/180). Работают и без «удобного Чужого»; нажал движение
посреди разворота — разворот обрывается, и Чужой сразу идёт. **T** — резкий разворот на 180°: стоя — анимацией разворота,
камера поворачивается вместе с телом; на ходу — взгляд сразу назад, тело разворачивается за ним.

**За Чужого.** Аманда прячется под картой (или над ней — выбор в меню, раздел «Чужой: осмотр, голос, Аманда») и,
когда берёшь её обратно, стоит там же, где стояла; пока Чужой вылезает из вентиляции, она на время возвращается домой.
Интерфейс Рипли (патроны, фонарь, подсказки «взять») спрятан, вместо него внизу по центру — HUD Чужого: где он, как идёт,
цель, стрелка на Аманду. Слюни и дым изо рта игра показывает, только когда Аманда ближе 6 м; галочка «Слюни и дым изо
рта всегда» (по умолчанию включена) оставляет их, пока камера на Чужом. Там же в меню — кнопки всех звуков, автозвуки и их частота. Сам Чужой подаёт только звуки поиска (ищет, начинает поиск, потерял след); «заметил» и «бросок» — только когда его цель — человек рядом (не андроид и не Аманда); крики боли сам не издаёт.

**Чужой против андроидов.** Игра андроидов Чужому в цели не даёт. С галочкой «Чужой атакует андроидов» (раздел «Атака
и ИИ», по умолчанию стоит): ЛКМ, когда андроид в 4 м перед Чужим, — Чужой убивает его так же, как человека: на время
удара мод считает андроида гражданским, и оба играют анимацию убийства человека. Если вдруг не вышло — через 3 с мод
добивает андроида прямым ударом. Режим «Прямой удар» (там же) — сразу смертельный удар без анимации Чужого.

**Лицехват атакует кого угодно.** За лицехвата ПКМ выбирает цель — любого живого персонажа рядом (люди, андроиды;
Аманду — только если в меню разрешено; Чужой — не жертва), ЛКМ — атака на выбранного (или на ближайшего перед собой).
Дальше 1.8 м — лицехват сам подбегает (WASD — отмена), потом прыгает — настоящий прыжок игры (анимация атаки лицехвата),
а жертва умирает с анимацией «лицехват на лице» (ACT_DEATH_FROM_FACEHUGGER), пока лицехват держится за неё. Андроид на
время атаки считается человеком. Если игра прыжок не запустила — жертва всё равно умирает (без прыжка).

**За андроида (Working Joe).** Андроиды — в том же списке, что и лицехваты («Лицехваты и андроиды», H — следующий).
WASD, Пробел/Shift/Ctrl — скорость, R — стрейф, ПКМ — выбрать цель, ЛКМ — подойти и ударить/задушить (как андроиды
в игре). Не убил за 4 с — жертва всё равно умирает. Нужна свежая установка (AlienModSetup.exe → «Установить») и
перезапуск игры: ветка андроида — в файле поведения.
**G** — андроид говорит (реплики игры по очереди: «Назад», предупреждение, «заподозрил», поиск, атака...), **Shift+G** —
случайная реплика; последняя видна в HUD. У остальных андроидов — свой режим ИИ (раздел «Лицехваты и андроиды»):
ручное (стоят), «игнор Аманды» и полный ИИ; «ИИ для всех» (F4) ставит его и андроидам.

**Свой HUD у каждого.** Чужой — «кость и янтарь», лицехват — розовый (прыжок, «на лице жертвы», подсказки Пробел/WASD),
андроид — бирюзовый «Seegson» (что делает, последняя реплика, клавиши).

**Удобный Чужой** (галочка в разделе «Движение»). Отпустил клавиши — Чужой останавливается почти сразу: мод гасит запрос
движения и завершает узел «срочно», поэтому анимации остановки WALK/CHARGE_TO_IDLE не доигрываются. Выключено — как в игре.

**Ходьба лицехвата, как у Чужого.** **R** — стрейф: тело смотрит туда же, куда камера, A/D — шаг вбок, S — пятится
(у лицехвата для этого свои анимации). Ещё раз R — обычная ходьба (поворачивается по ходу движения).

**Спавн куда угодно.** В разделе «Спавн» — «Куда ставить»: как задумано уровнем / куда смотрит камера (центр экрана) /
перед персонажем. «Лицехвата сюда» (**Ctrl+H**, в фоторежиме — **H**) — ещё один лицехват туда, куда смотрит камера: в
фоторежиме долети фрикамом куда хочешь и жми H. Лицехвата мод узнаёт в списке спавна после его первого спавна (F7 —
найти, F8 — заспавнить; в списке появится «[лицехват]») — дальше хоть сколько (лимит игры — 16 персонажей).

**Мультиплеер (первый слой, раздел «Мультиплеер»).** Связь двух игр через Steam — порты открывать не нужно. Каждый
выбирает роль (хост — Аманда, его мир главный; клиент — Чужой), вставляет Steam ID напарника (кнопка «Скопировать мой
ID», подойдёт и ссылка на профиль или код друга) и жмёт «Подключиться»; можно и так: один подключается, второй жмёт
«Принять». Видно состояние, пинг, имя и облик напарника. **Облик** — кем тебя видит напарник (Аманда, Эллен Рипли,
Ренсом, Рикардо, Сэмюэлс, Тейлор, Марлоу, Уэйтс, Аксель, Хьюз, Даллас, Паркер, Ламберт): пока он запоминается и уходит
напарнику, а надеть его на куклу — следующий шаг (кукол ещё нет). **Выходы сущностей**: хост шлёт события мира
(дверь открылась, свет, шаг скрипта), клиент повторяет их у себя и гасит свои такие же; тиканье и мигание отсеиваются
сами. Журнал выходов показывает, что происходит, и любой выход можно «Повторить». «Самопроверка Steam» — пакет самому себе.
Друзья, которые сейчас в Alien: Isolation, видны списком — «Подключиться» одним нажатием, ID вводить не нужно. Роль можно
не выбирать: при подключении возьмётся противоположная напарнику. Если напарник, к которому уже подключался, постучится сам —
соединение примется само. Всё о подключении пишется в **AlienModUI.mp.log** рядом с модом (он не стирается при обновлении
мода) — пришли его, если не соединяется. Галочка «Кнопки в меню игры (экспериментально)» добавляет пункт «Мультиплеер»
прямо в главное меню игры и в меню паузы.
**Клиент играет за Чужого, андроида или лицехвата** — выбери до подключения («Клиент играет за»): когда загрузится уровень,
мод сам отдаст управление. **Уровень хоста грузится сам**: при подключении (и когда хост переходит дальше) у клиента
загружается уровень хоста — с его начала (галочка «Грузить уровень хоста»).

**За лицехвата.** Если на уровне есть лицехваты, **H** (или кнопка в меню, раздел «Лицехваты») даёт играть за
ближайшего к Аманде, ещё раз H — за следующего. Камера за спиной, у лицехвата своя настройка (колесо мыши, раздел
«Камера» — пока играешь за него), у Чужого она не меняется. WASD — бежать (Ctrl — тихо, Shift — быстро, Пробел — во весь
опор), ЛКМ — прыжок на цель, ПКМ — сменить цель. На Аманду он не прыгает, пока в меню не разрешишь (это её смерть).
У остальных лицехватов (и у того, которого отпустил) такие же режимы ИИ, как у Чужого: ручное (стоят), «охотятся, но не на Аманду» (кто нацелился на неё, замирает и ищет другую цель) и полный ИИ. Пока играешь за лицехвата, «полный» у остальных работает как «не на Аманду»: к Рипли они теряют интерес. В разделе «Атака и ИИ» есть «ИИ для всех»: один режим сразу Чужому и лицехватам, F4 переключает его по кругу. Движение «само»: сначала напрямую, как Чужой, а если так
лицехват не сдвигается — по навмешу (можно выбрать вручную). Нужен обновлённый `_DIRECTORY_CONTENTS.BML`: закрой игру,
запусти `AlienModSetup.exe` → «Установить», загрузи уровень заново — иначе мод напишет «нет ветки мода».

**Машинима в фоторежиме.** Стрелки ведут персонажа относительно взгляда камеры (↑ — от камеры): Чужого или лицехвата /
андроида, за которого играешь. **Tab** — кого ведут стрелки (или камеру), **PgUp/PgDn** — скорость (правый Shift — бегом,
правый Ctrl — тихо), **Enter** — атака, **G** — голос, **T** — камера стоит / едет за персонажем / едет и смотрит на него.
Всё это и на странице «Фоторежим». Время должно идти (X — стоп-время).

**Голос андроида** — настоящие реплики андроидов игры (их «динамический диалог»): «предупреждение», «вижу человека»,
поиск, болтовня, захват, добивание... **Удар андроида** — убийство человека из анимаций игры (kill vs human).

Фоторежим (F9): WASD — лететь, Q/E — вниз/вверх, мышь — смотреть (стрелки — тоже, если Tab отдал их камере), Z/C — наклон (R — сброс), колесо — FOV
(меняется плавно, небольшими шагами; Ctrl+колесо — совсем точно, Shift+колесо — крупно),
X — остановить время (замирают анимации, ИИ и физика — хвост тоже), F — фокус (глубина резкости) на то, что в центре,
Shift/Ctrl — быстрее/медленнее. Уровень рисуется от фотокамеры: игра выбирает, что видно, по комнате, где камера, а не
по комнате Аманды. Esc фоторежим не сбрасывает, остальные клавиши мода (F1–F8, B, E...)
в нём не срабатывают. Пока открыто меню (Delete), курсор свободен, а камера стоит на месте: удобно крутить экспозицию и
другие ползунки. Постобработка — на странице «Фоторежим»: пресеты (нуар, тёплый, холодный, плёнка 1979...), экспозиция, цвет,
свечение и его порог, глубина резкости (фокус кликом по кадру или F, фокусное в мм, диафрагма f/…), искажение линзы,
аберрация, виньетка, зерно (зерно уровня в фоторежиме выключается — ставится своё), резкость (свой проход по кадру),
размытие, каше 2.39:1 / 1.85:1 / 4:3 / 1:1 / 9:16 и сетка третей, «спрятать интерфейс игры».

После загрузки уровня Чужой остаётся там, где его поставила игра; сразу выводить его к Аманде можно галочкой
«Сразу выводить Чужого» в разделе «Вентиляция» (по умолчанию выключено). В вентиляции WASD ведут самого Чужого. Карта вентиляции (F3) показывает вентиляции, его след и Аманду,
а зелёным отмечает ту, через которую он вылезет по E. E за Чужого — выход через ближайшую к нему вентиляцию (мод сам
подставляет её игре, Аманду никуда не переносит; если Чужой не вылез — пробует следующую, всего три). Q — выход у Аманды:
вентиляцию выбирает игра («фланговую» — сзади или сбоку от Аманды), а если такой нет — ближайшая к Аманде.
E и Q срабатывают на нажатие: удерживать не нужно, повторное нажатие — отмена.

В `AlienModUI.ini` также запоминаются клавиши, стрейф, «Аманда следует», «Сразу выводить Чужого», скорость
и мышь в фоторежиме и вся постобработка. Режим ИИ не запоминается: каждый запуск начинается с ручного управления.

В меню, в разделе «Экран — что показывать», по отдельности включаются подсказки, статус, карта и списки, а ещё
выбираются угол экрана и прозрачность. Настройки сохраняются в `AlienModUI.ini` рядом с DLL.

Шрифты — из самой игры: Isolation (как в меню игры) для текста и Jixellation (терминалы Seegson) для заголовков.
Мод достаёт их при запуске из `DATA\UI.PAK` установленной игры (файлы шрифтов в папку мода не кладутся);
символов, которых в них нет (тире, стрелки), добирается из Segoe UI.

Оформление меню — в стиле терминалов Seegson из Alien: Isolation: зелёный фосфор на чёрном, полосы развёртки ЭЛТ,
уголки-скобы на окнах, клавиши в рамках, свой курсор с «пингом» датчика движения при клике. Вместо стандартных значков
ImGui нарисованы свои: шевроны вместо треугольников, квадратная «лампочка» вместо галочки, ромб вместо круглой
радиокнопки (правки помечены `AlienMod` в `libs/imgui/imgui_draw.cpp` и `imgui_widgets.cpp`).

Язык меню — русский или английский (выбор вверху страницы «Главное»; по умолчанию — язык Windows).

### English

Hotkeys: **B** play as the Alien / back to Amanda, **WASD** walk (**Ctrl** sneak, **Shift** fast, **Space** run), **mouse wheel** camera distance (Shift/Ctrl + wheel — height / sideways, middle button — reset), **LMB/RMB** attack /
next target, **E** vents (hide / come out here / cancel), **Q** come out near Amanda, **V** behind/head view,
**Z** (hold) LOOK where the camera looks, **G** Alien voice, **F2/F3** on-screen hints / vent map, **F9** photo mode, **Delete** (rebindable) / **Insert** menu. Also:
**R** strafe, **F** Amanda follows, **C** path mode (ducts), **F1** characters,
**F4** AI cycle, **F5** panic reset, **F7/F8** spawn.
The head view can be free (mouse look, the Alien walks where you look) or attached to the head bone; turning on the spot is a toggle for each view. The menu language can be switched at the top of the Main page.

Спавн: поиск идёт по всей памяти игры в фоне (без дублей), имя объекта становится известно после его первого спавна.
Повторный спавн того же объекта — только Shift+F8 (он даёт копии, например второго Чужого, и может уронить игру),
больше 16 персонажей мод не даст — дальше игра падает.

Сборка: `dev\build.bat` (Visual Studio или MSYS2 MINGW32). Игру закрывать не нужно: инжектор внедряет не саму
`AlienModUI.dll`, а её копию из папки `live`, так что DLL свободна для пересборки.

**Обновить мод без перезапуска игры:** `dev\build.bat`, потом снова `runUI.bat`. Инжектор сам отцепит версию, которая
сейчас в игре, и подцепит новую. Отцепляемая версия возвращает игре всё, что держала: камеру, рубильники дерева, время,
HUD и Аманду. Новой она передаёт найденные узлы дерева, поэтому та продолжает с того же места посреди уровня, с тем же
Чужим или лицехватом и той же камерой. Отцепить мод вручную можно в меню: раздел «Обновить мод без перезапуска игры».
Отцепленная версия остаётся в памяти игры до её закрытия, но ничего не делает. Если в игре версия старше этой (без
отцепления), инжектор попросит один раз перезапустить игру.

Одна копия мода на игру: если мод уже запущен (старая AlienMod.dll или DevTools со встроенным модом), новая DLL
просто не загрузится, а не уронит игру. Старый DevTools .asi лучше убрать из папки игры — это второе ImGui-меню.
Вернуть оригинальное дерево поведения — `AlienModSetup.exe` → «Удалить из игры».

Пересборка: `CMakeLists.txt` (Visual Studio `-A Win32` или MSYS2 MINGW32); exe и dll кладутся в корень папки.
Код меню и уровней для этой сборки — `standalone/standalone.cpp`, остальное общее с DevTools.

# Alien Playable внутри DevTools

Мод «играть за Чужого» (раньше `AlienInjector.exe` + `AlienMod.dll` с окном-оверлеем) теперь собирается
в тот же `AlienIsolation.DevTools.asi` и управляется из ImGui. Инжектор и Python/Frida больше не нужны.

## Сборка
`AlienIsolation.DevTools.sln` → Release | Win32 → Build. MinHook лежит в `libs/minhook` (исходники v1.3.3),
в проект уже добавлен вместе с `AlienMod/*.cpp`. Для кириллицы в исходниках включён ключ `/utf-8`.

## Установка
1. Дерево поведения Чужого по-прежнему нужно положить в игру: `AlienModSetup.exe` → «Установить»
   (копирует `_DIRECTORY_CONTENTS.BML`). Без него мод не найдёт свои рубильники в дереве Чужого.
2. `build\AlienIsolation.DevTools.asi` (+ ASI-лоадер `winmm.dll`) — в папку с `AI.exe`, как раньше.
3. Запуск игры. Хуки мода ставятся сами при старте (лог — `AlienMod.log` рядом с `.asi`).
4. **Delete** — меню. Там окно «Alien Playable — управление» и блок смены уровня в «Settings».

## Что где
| Файл | Что делает |
|---|---|
| `AlienMod/mod_main.cpp` | запуск мода из `DllMain` DevTools, сброс при смене уровня, флаги ImGui |
| `AlienMod/ui.cpp` | окна ImGui: управление, HUD-статус, лог; очередь команд и снимок состояния |
| `AlienMod/control.cpp` … `spawn.cpp` | логика мода без изменений по сути; клавиши вынесены в функции `Act*()` |
| `GAME_LEVEL_MANAGER.*` | список уровней прямо из движка, текущий уровень, загрузка по указателю или имени |
| `Menu.cpp` | шрифт с кириллицей, окна мода, новый блок смены уровня, ввод при открытом меню |

## Потоки
ImGui рисуется в потоке `Present` и **не трогает** состояние мода напрямую: кнопки кладут команду в очередь,
которую задача планировщика выполняет под общим замком мода, а для отображения раз в 150 мс собирается снимок.

## Что изменилось по сравнению с отдельной DLL
- Хуки `queue_level` / `request_next_level` ставит только DevTools (Detours) и из них зовёт `AlienMod::OnLevelChange`;
  мод эти два адреса больше не перехватывает. `find_parameter<String/bool/Vector>` перехвачены обоими:
  MinHook встаёт поверх прыжка Detours (мод стартует после коммита Detours).
- Горячие клавиши те же. Галочка «Горячие клавиши мода» их выключает (WASD/стрелки и ЛКМ остаются).
  Пока в ImGui набирается текст, клавиши мода молчат; пока открыто меню, ЛКМ не атакует.
- Пока меню открыто, блок ввода Аманды пропускает сообщения окна к ImGui, а до игры не доходят клики и нажатия,
  которые забрал ImGui (отпускания клавиш проходят всегда, чтобы ничего не залипало).
- Экземпляр менеджера уровней читается из глобала игры `*(*(0x016F0C88) + 0x3C)`, поэтому смена уровня работает
  сразу, а не только после того, как игра сама вызовет `get_level_from_name`.
- `set_withdraw_state` в DevTools раньше всегда подменял состояние на `NeedsToWithdraw` (Чужой постоянно рвался
  в вентиляцию). Теперь по умолчанию состояние игры не трогается; старое поведение — галочкой в меню.
- «Force Alien withdrawl» неактивна, пока игра сама не вызвала `request_withdraw` (иначе вызов с `this = nullptr`).
