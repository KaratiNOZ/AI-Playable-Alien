Промежуточная beta-сборка управления и камер. Установка и обновление — как в предыдущем релизе: распаковать архив, использовать установщик и `runUI.bat`.

Изменения:
- Ползание F6 использует штатную позу игры; обычная скорость возвращается после вставания.
- Автоматический вход и выход из горизонтальной вентиляции движением в отверстие. Ручной режим пути C убран; C фоторежима сохранена.
- Исправления восстановления движения после разворотов, скачка камеры при смене позы и прокрутки меню.
- Камера T управляет собственной орбитой FollowBehavior по cubic Bézier ease-in-out и следует фактическому направлению разворота. Для ползания запрашивается штатное действие вместо процедурного поворота модели.
- Ускорение собственных анимаций разворота; «Удобный Чужой» пропускает начало ходьбы, а не только остановку.
- Первый вид читает позицию головы напрямую; смещения задаются в постоянных осях тела и не переактивируют камеру при каждом изменении.
- Мультиплеер скрыт из обоих меню, код сохранён. Добавлено автоматическое осматривание в покое для сетевого игрока за Чужого, снимаемое кнопками движения.
- Следование Аманды осталось только в меню. F освобождена для будущего осмотра укрытий.

Ограничения этой промежуточной сборки:
- Камера T от третьего лица поворачивается, но может дёргаться и сбрасывать ракурс в конце. Синхронизация Bézier ещё не завершена. Анимация поворота в ползании и последующее движение подтверждены игроком.
- Освещение и видимость в шахтах остаются экспериментальными: проблему полной темноты исправленной не считаем.
- Неотменяемое отступление от огнемёта, осмотр шкафов/столов на F, стереозвук и реакции NPC ещё не входят в релиз.
- Новые действия камер требуют дальнейшей проверки в игре; релиз остаётся beta.

Проверки: сборка x86 Release, только системные зависимости DLL; тесты Bézier, жизненного цикла ползания и переходов горизонтальных шахт; проверка состава и целостности ZIP.

В архиве — установщик, инжектор, DLL, запуск, README и файлы поведения. Личных настроек, логов и инструментов разработчика нет.
