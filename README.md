<a name="english"></a>
## 🇬🇧 English

<p align="center">
  <b>Play as the Alien, Facehugger, and Android in Alien: Isolation.</b>
</p>

Gagen's Playable Alien is a mod that lets you take control of different creatures and characters from Alien: Isolation, using their native animations, movement and abilities.

> **Beta Notice:** The mod is still under development. Bugs and occasional crashes may occur. Please report issues in the repository.

**Requirements**
- Windows 10 / 11
- Steam version recommended (`AI.exe` from `17.02.2015`)
- No additional software required

### Update — 16 November 2026

**0.21-beta (interim build)**

- Improved Alien turning animations and movement.
- Updated third-person and first-person camera behavior.
- Added automatic entry and exit for horizontal vents.
- Improved floor crawling and menu behavior.
- Multiplayer menus temporarily hidden; network backend retained.

**Known Issues:** Third-person camera jitter, unfinished Bézier synchronization, experimental duct visibility and lighting. Audio and NPC reactions are still in development.

### 🚀 Quick Start

1. Unpack the archive **anywhere except `Program Files`**.
2. Close the game.
3. Run `AlienModSetup.exe` and click **"Install"**.
4. Start the game.
5. Run `runUI.bat` or `AlienInjectorUI.exe`.
6. Press **Delete** or **Insert** in-game to open the mod menu.

> *To uninstall:* Run `AlienModSetup.exe` → **"Remove from game"**.

### ⌨️ Controls

| Key | Action |
| :--- | :--- |
| **B** | Play as the Alien / Return to Amanda |
| **WASD** | Movement |
| **LMB / RMB** | Attack / Select target |
| **E** | Vent interactions |
| **Q** | Emerge near Amanda |
| **V** | Switch camera view |
| **Z (hold)** | Turn towards camera crosshair |
| **G** | Alien voice |
| **H** | Switch to Facehugger / Android |
| **F6** | Toggle floor crawling |
| **F9** | Photo mode |
| **Delete / Insert** | Open / Close mod menu |

### 🦠 Other Features

- **Facehugger:** Select nearby targets and leap to attack.
- **Android:** Play as a Working Joe, move and attack.
- **AI Modes:** Configure behaviors of other Facehuggers and androids.
- **Photo Mode:** Free camera, time control and post-processing effects.

## 🇷🇺 Русский

<p align="center">
  <b>Играйте за Чужого, Лицехвата и Андроида в Alien: Isolation.</b>
</p>

Gagen's Playable Alien — мод, позволяющий управлять разными существами и персонажами из Alien: Isolation, используя их оригинальные анимации, передвижение и способности.

> **Бета:** Мод находится в разработке. Возможны баги и вылеты. Пожалуйста, сообщайте о проблемах в репозитории.

**Требования**
- Windows 10 / 11
- Рекомендуется Steam-версия (`AI.exe` от `17.02.2015`)
- Дополнительное ПО не требуется

### Обновление — 16 ноября 2026

**0.21-beta — промежуточная сборка**

- Улучшены анимации разворота и передвижение Чужого.
- Доработано поведение камеры от первого и третьего лица.
- Добавлен автоматический вход и выход из горизонтальной вентиляции.
- Улучшены ползание по полу и работа меню.
- Мультиплеер временно скрыт из меню, сетевой код сохранён.

**Известные проблемы:** Подёргивания камеры от третьего лица, незавершённая синхронизация Bézier, экспериментальные видимость и освещение вентиляции. Звук и реакции NPC ещё в разработке.

### 🚀 Быстрый старт

1. Распакуйте архив **куда угодно, кроме `Program Files`**.
2. Закройте игру.
3. Запустите `AlienModSetup.exe` и нажмите **«Установить»**.
4. Запустите игру.
5. Запустите `runUI.bat` или `AlienInjectorUI.exe`.
6. В игре нажмите **Delete** или **Insert**, чтобы открыть меню мода.

> *Для удаления:* Запустите `AlienModSetup.exe` → **«Удалить из игры»**.

### 🦠 Другие возможности

- **Лицехват:** Выбор ближайших целей и прыжок для атаки.
- **Андроид:** Управление Рабочим Джо, передвижение и атаки.
- **Режимы ИИ:** Настройка поведения других лицехватов и андроидов.
- **Фоторежим:** Свободная камера, управление временем и эффекты постобработки.
